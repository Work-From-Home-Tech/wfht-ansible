# Ansible Role: install-ca-cert

This Ansible role installs a CA certificate on Ubuntu/Debian and RedHat-based systems.

## Requirements

- Ansible 2.9 or higher
- Root access on target systems

## Role Variables

None

## Dependencies

None

## Example Playbook

```yaml
- hosts: servers
  roles:
    - role: install-ca-cert
```
